# al-Wird al-Laṭīf: open edition

A free, phone-first edition of *al-Wird al-Laṭīf*, the morning and evening
litany of Imām ʿAbd Allāh ibn ʿAlawī al-Ḥaddād (1044–1132 AH). It has vowelled
Arabic, the Qurʾānic passages in the Madinah muṣḥaf script, transliteration,
and meanings in English, plus the Qurʾān translations in German, Hausa and
Dagbanli. Compiled by Mohammed Sadat Abdulai.

**Status:** edition 1.0 (October 2026), being turned into an open
multilingual website and per-language PDFs (see SPEC.md). The duʿā Arabic and
the Hausa and Dagbanli texts are **not yet proofread**; see REVIEW.md.

Hosted on GitHub; the website will be published with GitHub Pages, built by GitHub Actions.

## Build

```sh
# Website (TanStack Start + React; also editable in Lovable)
bun install
bun scripts/build-wird-data.ts      # regenerate src/data/wird.json after editing data/ or i18n/
bun run dev
bunx vitest run

# PDF
pip install -r requirements.txt     # WeasyPrint 70.0, PyYAML, pytest, pikepdf
# The Inter font must be installed system-wide (Debian/Ubuntu: apt install fonts-inter)
python3 pdf/build.py                # → build/al-Wird-al-Latif.pdf
python3 -m pytest -q                # data checks + glyph-level comparison with tests/baseline/
```

## Layout

| Path | What |
|---|---|
| `data/wird.yaml` | the wird: sections, items, repeat counts, duʿā Arabic, Qurʾān references |
| `data/translit.yaml` | transliteration (a separate, replaceable layer) |
| `i18n/<lang>.yaml` | per-language metadata, titles and duʿā meanings |
| `data/transcriptions/` | Hausa and Dagbanli Qurʾān translations typed from print (third-party) |
| `data/kfgqpc/`, `data/quranenc/` | published Qurʾān text, font and translations, unchanged |
| `src/`, `public/` | the website; `src/data/wird.json` is generated by `scripts/build-wird-data.ts` |
| `pdf/` | the PDF build (`build.py`) and the YAML loader/validator (`wird_data.py`) |
| `tests/` | Python tests and the edition 1.0 baseline PDF; website tests are in `src/test/` |
| `docs/DATA.md` | the data format |
| `AGENTS.md` | rules for everyone editing the repository, including Lovable |

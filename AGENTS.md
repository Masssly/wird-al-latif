# al-Wird al-Laṭīf website

Read content/SPEC.md, content/HANDOFF.md and content/REVIEW.md before changing text or features.

- `content/` mirrors the data of the GitHub repo Masssly/wird-al-latif (YAML + third-party Qurʾān data); it is the single source of truth — edit it, never the generated JSON. Why: the PDF build reads the same files.
- `src/data/wird.json` is generated by `bun scripts/build-wird-data.ts`; rerun it after any change in `content/`. Why: the browser must not load the 3.5 MB KFGQPC file.
- Never modify KFGQPC/QuranEnc text or fonts, never "fix" unproofread Arabic/Hausa/Dagbanli from memory, copy Arabic code point for code point. Why: owner's licensing and proofreading rules.
- Colour-code rules in `src/lib/wird.ts` are a port of the PDF's `src/build.py`; keep them in sync. Why: web and PDF must match.
- Fonts are self-hosted in `public/fonts`; no CDNs, analytics or third-party scripts. Reader progress lives only in localStorage. Why: project privacy rules.
- Offline via `public/sw.js` (network-first pages); not registered in the editor preview. Why: new versions must show on reload.
